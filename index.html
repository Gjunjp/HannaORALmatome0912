【出題 / 練習問題】

☆次の問題を読んで、問題に対する答えを先に1分30秒考えてください。そして、指示があった後、1分30秒以内であなたの回答を録音してください。

テーマ：
日本では、仕事が終わったら上司に連れられてお酒を飲みに行く習慣がありました。
①これについてどう思いますか？
➁もしあなたが上司に誘われたら一緒に行きますか？
ご意見を述べてください。

【回答内容】

仕事が終わった後に 上司と一緒に お酒を飲むのは そんなに悪いことではないと思います。
（※原文：あまり悪いことではないと思います → 意味は通じるが上記の方が自然）

ときどき一緒にお酒を飲んで、同僚との仲が良くなることもあります。
一緒に仕事について話し合ったり、プライベートの趣味の話をしたりして、関係(かんけい)が良くなると将来の仕事の時に役に立ちます。

でも健康の為にあまり頻度(ひんど)/回数が多くない方がいいです。

※フィードバック：録音時間 32秒。あと３文ほど長く話せるといいですね。

➂このような店は ちょっと危ない感じがします。

0912 ≪第3部 口頭試問≫

【出題 / 練習問題】

☆録音されてある質問に対して、あなたの回答を録音してください。
（１〜５番：各15秒 / ６〜10番：各30秒）

４番：日本に旅行したら、何か買いたいものはありますか？なぜですか？

→（買いたいものが）あります。
A：薬やブランドのバッグや綺麗な服など、台湾より日本で買えばもっと安いものがあるからです。
B：日本でしか買えない、いろいろな種類の物がたくさんあるからです。

※回答時間は15秒なので、A又はBのどちらか答えればOK。
５番：ペットがいる生活をどう思いますか？

→一人暮らしは自由ですが、ときどき寂(さび)しい思(おも)いがするので、ペットがいると、寂しくなくていいと思います。

※語彙のポイント：
・寂しい…読み方基本は「さびしい」。「さみしい」は話し言葉。
・寂しい感じ…情景、雰囲気。
・寂しい思い…心の中の感情。
６番：もし生まれ変わるなら男性がいいですか？女性がいいですか？なぜですか？

→もし生まれ変わるなら男性がいいです。
女性とは違う経験や人生が体験できて面白いと思います。
男性に生まれるのも悪くないかもしれません。

７番：最近子供を産みたくない、という若者が増えています。どう思いますか？

→この問題は難しいです。
たぶん若い人はお金が少ないです。それに仕事が忙しいです。
自分で子供の面倒をみる事が難しいので、子どもを産みたくないと思います。

８番：貯金が多い人にはどんな特徴があると思いますか？

→貯金が多い人達もみんなそれぞれ違う性格や特徴があると思いますが、お金を気にしているという特徴があると思います。
それからお金の管理(かんり)や運用(うんよう)ができる人が多いと思います。

※語彙のポイント：理財 = お金の管理
9番：台湾には朝食のお店がたくさんありますが、それはどうしてだと思いますか？

→みんな外で朝ご飯を食べることに慣れているからだと思います。
それに仕事をしている人は朝忙しいので、朝ご飯を準備する時間がありません。
外のお店で手軽に温かいサンドイッチやトースト等買うことができればとても便利だから、朝食のお店がたくさんあるのだと思います。

10番：あなたはマイホームが欲しいですか？ また、どんな生活を送りたいですか？

→私は自分の家が欲しいです。
私は一人暮らしをして自由な生活を送りたいです。
他の人の話を聞く必要が無いので自由だし、自分の好きな物を自分で決めて買うことができるからです。

※フィードバック：（可以再多點說想要過什麽樣子的生活）

0907 ≪第2部 翻訳≫

【出題 / 練習問題】

☆一分間以内で１番から5番までの文を翻訳してください。

① 今天是2023年9月9日。

→ きょうは にせんにじゅうさんねん くがつ ここのか です。

② 請問老師要不要喝茶呢?

→ 先生お茶はいかがですか？

※文法補充：
「先生、（私と先生は）お茶をいただきませんか？」
いただく（もらう・食べる・飲むの謙譲語）→ いただきます（マス形）
→ 丁寧な誘い、勧誘の文（老師我們要不要喝茶呢？ ※別人有準備茶）

「先生、（私に）お茶をいただけませんか？」
いただく → いただける（可能形）→ いただけます（マス形）
→ 丁寧な依頼の疑問文（例：答えを教えて＋いただけませんか？）
➂ 我喜歡一邊喝咖啡一邊看書。

→ 私はコーヒーを飲みながら本を読むのが好きです。

④ 我去北海道的時候有滑雪,也泡了溫泉。

→ スキーをしたり、温泉に入ったりしました。

⑤ 這裏雖然好玩,但是很冷。

→ ここはおもしろいですが、寒かったです。

※注意：おもしろい → 面白かった（過去形）。時態要一致。
0907 ≪第3部 口頭試問≫

【出題 / 練習問題】

☆録音されてある質問に対して、あなたの回答を録音してください。
（１〜５番：各15秒 / ６〜10番：各30秒）

１番：昨日雨が降りましたか？

→昨日雨が降りました。私が出かけるとき急に大雨が降りだしました。

※文法ポイント：降る（マス形）＋だす ＝ 開始下雨
２番：台湾のお薦めの観光地をあげてください。

→お薦めは夜市(よいち)や、ちゅうせいきねんどう（中正紀念堂）、きゅうふん（九份）、ディンタイフォン（鼎泰豐）等です。

３番：読書は好きですか？また、そのわけは？

→読書(どくしょ)は好きです。本から面白いことを学(まな)ぶことができるからです。

※「学ぶ・習う・勉強する」の違い：
・学ぶ…自分で学ぶ。教師が無くても可能。（例：大学で心理学を学ぶ）
學得知識或技藝（身につけること）。包含接受指導、自學、經驗學習、模仿學習、抽象事物等。

・習う…他人から学ぶ。教師が必要。（例：ピアノを習う）
多指從某人身上學習知識或技藝，多為需要練習的實作技藝。

・勉強する…目標を持って学ぶ。教師が無くても可能。（例：大学で心理学を勉強する）
學習有關學問或技藝，有目標性地（如升學、考試、就職等目的）勤勉自強。多用於書本上的學習。
